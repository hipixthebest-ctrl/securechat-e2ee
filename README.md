# SecureChat 🔒

Веб-мессенджер с настоящим сквозным шифрованием (E2EE), WebRTC аудиозвонками и поддержкой PWA (установка в качестве приложения на мобильные устройства).

## 🚀 Стек технологий
- **Backend**: Node.js + Express + Socket.IO
- **Frontend**: Vanilla JS, Web Crypto API, WebRTC
- **Шифрование**: ECDH (Diffie-Hellman на эллиптических кривых P-256) + AES-256-GCM
- **Звонки**: WebRTC peer-to-peer аудио, STUN-серверы Google
- **Платформа**: PWA (Progressive Web App) для работы без браузерной строки

## 🔐 Как работает сквозное шифрование (E2EE)

В проекте реализован полноценный протокол Диффи-Хеллмана:
1. При входе в чат браузер пользователя генерирует пару ключей: **Приватный** и **Публичный**.
2. **Приватный ключ никогда не покидает устройство пользователя.**
3. Сервер получает только Публичный ключ и пересылает его собеседникам.
4. При отправке сообщения браузер Алисы берет *свой Приватный ключ* и *Публичный ключ Боба*, математически вычисляя общий секрет (**Shared Secret**).
5. Этим секретом сообщение шифруется по алгоритму `AES-256-GCM` и отправляется через WebSocket.
6. Сервер видит исключительно зашифрованный байт-код (кашу) и не имеет технической возможности прочитать переписку. Боб на своем устройстве выполняет аналогичную операцию и расшифровывает текст.

## 📱 Установка как приложение (PWA)

Благодаря настроенному `manifest.json` и iOS мета-тегам, чат можно добавить на экран телефона:
- **iOS (Safari)**: Откройте сайт, нажмите кнопку «Поделиться» (Share) ➔ «На экран "Домой"» (Add to Home Screen).
- **Android (Chrome)**: Откройте сайт, нажмите на три точки ➔ «Установить приложение».
